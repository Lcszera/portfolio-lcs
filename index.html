01. Sobre mim

Sou desenvolvedor focado no ecossistema Java, com Spring Boot, Spring Data JPA, Spring Security, Hibernate e PostgreSQL como base do meu dia a dia — sempre acompanhado de Thymeleaf, HTML, CSS e JavaScript no front-end. Gosto de pegar um problema real de um negócio (uma barbearia, uma empresa de manutenção industrial) e transformar em um sistema completo: autenticação, agendamentos, pagamentos, painéis administrativos e controle financeiro.

02. Projetos em destaque

AB Barbearia System

Em desenvolvimento

Sistema web completo para gestão de uma barbearia. Permite que clientes façam cadastro, login e agendamento online dos serviços, enquanto o administrador controla funcionários, planos mensais, serviços oferecidos, financeiro, galeria de fotos e equipe — tudo em um painel administrativo dedicado, com recuperação de senha e autenticação segura.

MF Manutenções

Em desenvolvimento

Sistema web para a MF Manutenções, empresa especializada em manutenção de máquinas para a indústria moveleira em Cuiabá e Várzea Grande (MT). O cliente cadastra sua empresa e solicita serviços — manutenção preventiva ou corretiva, esquadrejamento, manutenção de coleiro, visita técnica ou instalação de máquinas — e acompanha tudo pela "Minha Área". Os pagamentos são feitos via PIX, crédito, débito ou à vista com integração InfinitePay, com notificação por e-mail após a confirmação e um painel administrativo completo para gestão de pedidos, clientes e financeiro.

  • Java 21
  • Spring Boot
  • Spring Security
  • Spring Data JPA
  • Thymeleaf
  • PostgreSQL
  • InfinitePay
