01. Sobre mim

Sou desenvolvedor focado no ecossistema Java, com Spring Boot, Spring Data JPA, Spring Security, Hibernate e PostgreSQL como base do meu dia a dia — sempre acompanhado de Thymeleaf, HTML, CSS e JavaScript no front-end. Gosto de pegar um problema real de um negócio (uma barbearia, uma empresa de manutenção industrial) e transformar em um sistema completo: autenticação, agendamentos, pagamentos, painéis administrativos e controle financeiro.

AB Barbearia System

Concluído

Sistema web completo para gestão de uma barbearia: agendamento online, cadastro de clientes e painel administrativo.

  • Java 21
  • Spring Boot
  • Spring Security
  • PostgreSQL

Clientes se cadastram, fazem login e agendam serviços online. O administrador controla funcionários, planos mensais, serviços oferecidos, financeiro, galeria de fotos e equipe — tudo em um painel dedicado, com recuperação de senha e autenticação segura.

  • Cadastro de clientes
  • Login e autenticação
  • Agendamento online
  • Gerenciamento de funcionários
  • Planos mensais
  • Controle de serviços
  • Painel administrativo
  • Controle financeiro
  • Galeria e equipe
  • Recuperação de senha
  • Java 21
  • Spring Boot
  • Spring Security
  • Spring Data JPA
  • Thymeleaf
  • PostgreSQL

MF Manutenções

Em desenvolvimento

Sistema web para uma empresa de manutenção de máquinas da indústria moveleira, com solicitação de serviços e pagamento online.

  • Java 21
  • Spring Boot
  • InfinitePay
  • PostgreSQL

Desenvolvido para a MF Manutenções (Cuiabá e Várzea Grande - MT). O cliente cadastra sua empresa e solicita serviços — manutenção preventiva/corretiva, esquadrejamento, manutenção de coleiro, visita técnica ou instalação de máquinas — e acompanha tudo pela "Minha Área". Pagamentos via PIX, crédito, débito ou à vista com integração InfinitePay, e notificação por e-mail após confirmação.

  • Cadastro de clientes (empresa/CNPJ)
  • Login e autenticação
  • Solicitação de serviço
  • Pagamento via PIX / cartão (InfinitePay)
  • Painel "Minha Área" com histórico
  • Painel administrativo
  • Notificação por e-mail
  • Recuperação de senha
  • Java 21
  • Spring Boot
  • Spring Security
  • Spring Data JPA
  • Thymeleaf
  • PostgreSQL
  • InfinitePay
